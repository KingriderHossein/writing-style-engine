# Evidence and Source Register

Register version: 0.1.0

This is the progressive-loading index for the evidence register. Use non-Persian sources only. Rank sources by methodological relevance before popularity. Prefer datasets, code, reproducible methods, benchmarks, controlled examples, human evaluation, measurable dimensions, and explicit editorial workflows.

Do not infer Persian perceptual effects from English results. English-language sources can define hypotheses and methods; Persian thresholds require separate validation.

- `source-register-01-research-foundations.md` — Text Style Transfer, Controllable Text Generation, Stylometry, Authorship Style Transfer, Style Representation, Style Evaluation, Voice and Tone Systems.
- `source-register-02-editorial-and-summarisation.md` — Professional Content Style Guides, Journalism, Headline Writing, Narrative Journalism, Science Journalism, Social Media Writing, Lay Summarisation.
- `source-register-03-evaluation-and-multilingual.md` — News Summarisation, Engagement Research, Clickbait Detection, Semantic Preservation, AI-generated Content Evaluation, Multilingual Style Transfer, and ranked GitHub projects.
- `source-register-04-decisions-and-corpus.md` — include/reject decisions and corpus publication sources.

## Ranking grades

- **A**: direct evidence or operational rules suitable for v0.1 references.
- **B**: strong supporting evidence or a future implementation candidate.
- **C**: useful context, but too narrow, outdated, model-dependent, or weakly validated for direct v0.1 control.
- **Reject from v0.1 execution**: retain as research reference only; do not make runtime depend on it.

Normal Skill execution should load only the relevant split file(s).
